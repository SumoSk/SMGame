# Traffic Fixer Thailand

เกมสร้างเมืองและแก้ปัญหาจราจรแบบไทย แสดงผล 3 มิติด้วย Three.js

## เปิดเล่นบนเครื่อง

ติดตั้ง Node.js แล้วรันจากโฟลเดอร์โปรเจกต์:

```sh
npm start
```

เปิด http://127.0.0.1:4173 ในเบราว์เซอร์ที่รองรับ WebGL

## ทดสอบระบบเกม

```sh
npm test
```

## ไฟล์สำคัญ

- `dist/` — หน้าเกม สไตล์ ระบบจำลอง และตัวแสดงผล 3 มิติ พร้อม Three.js
- `outputs/Traffic-Fixer-Thailand-3D.html` — เกมฉบับรวมไฟล์ที่มากับต้นฉบับ
- `work/` — เซิร์ฟเวอร์สำหรับเปิดบนเครื่องและชุดทดสอบเดิม

ความคืบหน้าในเกมบันทึกใน localStorage ของเบราว์เซอร์ เมื่อเปลี่ยนโดเมนหรือเครื่อง เซฟเดิมจะไม่ย้ายตามอัตโนมัติ

นำเข้าจากต้นฉบับ Traffic Fixer Thailand บน ChatGPT Sites โดยคงไฟล์เกมเดิมไว้

## Parking v5 — Compact targeted plots

ย่อโมเดลลานจอด 10 แบบเพิ่มเติม: สำนักงานใหญ่ โรงงานกลาง ร้านค้ากลาง ร้านค้าใหญ่ ร้านอาหารกลาง ห้างเล็ก ห้างใหญ่ สวนกลาง สวนใหญ่ และผับใหญ่ ด้วยการจัดแถวช่องจอดให้พอดีกับความจุ ลดช่องจอดว่างในแถวและพื้นที่ปูลาดหน้าทางเข้า รวมทั้งปรับทางเดินรถภายในให้พอดีโดยไม่ลดจำนวนช่องจอด รองรับเฉพาะเซฟใหม่ของลานจอด v5 ส่วนเซฟเก่ายังคงเก็บอยู่แต่เปิดในเวอร์ชันใหม่ไม่ได้ ทดสอบรถเข้าออกครบสิบโมเดลแล้ว.

## เวอร์ชัน 1.2.0 — บัญชีและเซฟออนไลน์

เมนูสามขีดมี บัญชีผู้ใช้ (เปลี่ยนรหัสผ่านด้วยการตรวจรหัสเดิม และออกจากระบบ) และ เซฟเกม (สร้าง โหลด เขียนทับ ลบเซฟออนไลน์ โดยต้องยืนยันก่อนลบ). ยกเลิกปุ่มบัญชีที่ลอยบนหน้าจอและย้ายรายงานเมืองกับเริ่มเมืองใหม่ไว้ในหน้าเซฟเกม. เซฟใช้ Supabase `smgame_saves` พร้อม Row Level Security จำกัดเฉพาะบัญชีตนเอง; ไม่มีทางเข้าบันทึก/โหลดเซฟในเครื่องผ่าน UI หรือ Ctrl+S. ข้อมูลเซฟในเครื่องเก่าที่มีอยู่ไม่ถูกลบอัตโนมัติ.

## เวอร์ชัน 1.3.0 — ความปลอดภัยจราจรและลานจอด

เก็บต้นฉบับ 1.2.0 แบบแยกต่างหากในสาขา `backup-version-1.2` ซึ่งไม่ถูกแก้ไขหรือเขียนทับ

- ระบบเปลี่ยนเลน: เตรียมเลนเลี้ยวล่วงหน้าไกลขึ้น และทำช่วงขยับข้ามเลนให้เสร็จตั้งแต่ต้นทางตรงแทนการเบี่ยงก่อนถึงเส้นหยุดไฟแดง
- ระบบทางแยก: ตรวจตำแหน่งรถจริงบริเวณทางออกก่อนอนุญาตให้เข้ากลางแยก และอัปเดตตำแหน่งรถในดัชนีชนกันทันทีเพื่อไม่ให้ใช้ข้อมูลรถที่เคลื่อนแล้ว
- ระบบลานจอด: จัดสรรช่องจอดกระจายข้ามแถวจอด ไม่เติมฝั่งเดียว; ปรับหัวรถให้หมุนผ่านโค้งที่รัศมีปลอดภัย; ประสานรถเข้ารถออกที่ใช้ช่องทางในแถวเดียวกัน; ตรวจรถถนนที่กำลังผ่านประตูลานตอนรถออก
- ป้องกันติดล็อก: รถที่ติดค้างผิดปกติเป็นเวลานานมากจะเริ่มเส้นทางใหม่จากทางเข้าเมืองเป็นทางเลือกสุดท้าย โดยไม่ลบเที่ยวเดินทางและคืนช่องจอดเดิมให้ถูกต้อง
- ไม่ขยายขนาดแปลง parking v5 ไม่ลดจำนวนช่องจอด และไม่เปลี่ยนโครงสร้างเซฟ Parking v5 (เซฟ 1.2.0 ยังคงโหลดได้)

การทดสอบที่ฝังใน `npm test`: เพิ่ม `work/test-traffic-integrity.cjs` ครอบคลุมผังอาคาร 24 ชนิด×4 ทิศทาง (96 แบบ), ตรวจตำแหน่งรถจอด 6,464 จุด, การจัดสรรแถวจอดของ 10 โมเดล, การเลี้ยวแบบโค้ง, การกู้คืนรถติดล็อก, รถเข้าออกสวนกัน 10 โมเดลและการตรวจคู่รถไม่ให้ซ้อนทับในลานจอด

## เวอร์ชัน 1.4.0 — รถออกจากลานและกู้รถค้างที่ 60 นาทีเกม

- สำรองต้นฉบับ 1.3.0 อยู่ที่สาขา `backup-version-1.3` และไม่แตะสาขาแบ็กอัปเดิม
- ใน `dist/game.js`: รถ `parking_out` ไม่จองช่องถนนตั้งแต่เริ่มออกจากลานอีกต่อไป: รอที่คอทางออกจนช่องรถบนถนนและช่องถัดไปว่าง จึงเรียก `occupy()` เพื่อจองและเลี้ยวเข้าอย่างปลอดภัย รวมทั้งคงตำแหน่งรถบนเส้นทางให้สัมพันธ์กับช่องที่จอง
- `advanceLot()` รองรับเพดานระยะ เพื่อให้รถหยุดก่อนเข้าเลนโดยไม่ล้ำถนน และ `respawnVehicle()` ล้างสถานะการจองช่องถนนของรถที่ถูกกู้คืน
- เปลี่ยน `IMMOBILE_RESPAWN_TIMEOUT` จาก 200 เป็น **60 นาทีในเกม** และตรวจเวลาไว้ก่อนกระบวนการเคลื่อนที่สำหรับ `departing`, `parking_in`, `parking_out`, `driving`, `stuck` (รวมรถค้างในช่องจอดที่ยังไม่ได้สร้าง `lotPath`)
- รองรับเซฟจาก 1.3.0 ที่กำลังอยู่ในขั้น `parking_out` และเคยจองช่องถนนไปแล้ว โดยไม่จองซ้ำ
- เพิ่ม `work/test-parking-merge.cjs`: จำลองปิด/เปิดเลนถนน ณ ทางออก, ตรวจไม่มีการจองถนนล่วงหน้า, ทดสอบการกู้คืนครบทั้งห้าสถานะที่ 60 นาที และทดสอบรถออกพร้อมกัน 30 คัน
- ปรับ `work/test-parking.cjs` ให้ตรวจพฤติกรรมการรอที่จุดรวมเข้าถนนใหม่แทนการคาดหวังสถานะเก่า
- ไม่เปลี่ยนจำนวนช่องจอด ขนาดอาคาร ระบบเซฟออนไลน์ และเวอร์ชันรูปแบบเซฟ `PARKING_VERSION=5`

## เวอร์ชัน 1.5.0 — คอยหลบขวาและคำนวณเส้นทางใหม่ที่ปากทางลานจอด

- เก็บเวอร์ชัน 1.4.0 ก่อนแก้ไว้ที่สาขา `backup-version-1.4` โดยไม่เปลี่ยนสาขาแบ็กอัปก่อนหน้า
- `parking_out`: รถที่เตรียมออกจากลานหยุดอยู่ *ก่อนเลี้ยว* และยังไม่จองเลนของถนน จนกว่าจะมีทางออกว่างจริง โดยตรวจพื้นที่ตลอดแนวการเลี้ยว (ไม่ใช่ตรวจแค่รถต้นทาง)
- รถบนถนนที่กำลังเข้าใกล้ประตูทางเข้า/ออกที่มีรถค้าง จะสลับไปเลนขวาถัดไปได้ทันทีเมื่อตรวจว่าเลนทิศทางเดียวกันว่างจริง ทั้งทางตรรกะและตำแหน่งรถทางกายภาพ ไม่ไปขวางรถสวนทาง
- เมื่อหลบขวา จะคำนวณเส้นทางไปปลายทางใหม่ทันทีด้วยการค้นหา `route(...)` จากโหนดถนนปัจจุบัน โดยรักษาทิศทางเดินรถที่ถูกต้อง และอัปเดต `motionStartPose`, `motionSeedLane`, `emergencyInitialLane`, `occKey` พร้อมกัน ไม่ทำให้การแสดงภาพรถกับการจองช่องถนนขัดแย้งกัน
- รถที่ตั้งใจจะเข้าลานดังกล่าวเองไม่ถูกสั่งให้หลบจนเลยทางเข้า หากเลนขวาไม่ว่างให้คงตำแหน่งเดิม
- ยังคงระบบกลับประตูเมืองเมื่อหยุดนิ่งเกิน **60 นาทีเกม** จากรุ่น 1.4.0
- เพิ่ม `work/test-parking-emergency.cjs`: ตรวจจุดรอในลานว่ารถไม่เริ่มเลี้ยวและไม่ล้ำถนน, การหลบขวาและค้นเส้นทางใหม่, การเปลี่ยนข้อมูลตำแหน่ง/เลนพร้อมกัน, ปฏิเสธการย้ายเมื่อเลนขวาถูกจอง และการวิ่งจบทริปตามปกติ

## เวอร์ชัน 1.6.0 — รถออกจากลานจอดแบบไปต่อทันที (Arcade Exit Priority)

- รถที่ถึงปากทางออกเริ่มเลี้ยวและขับต่อเนื่องไปยังถนน แม้มีรถบนถนนหยุดนิ่งขวางอยู่ในเส้นทางเลี้ยว ตามกติกาเกมที่อนุญาตให้รถผ่านกันได้เฉพาะช่วงรวมเข้าถนนจากลานจอด
- การตรวจรถชนและการเว้นระยะในลานจอด **ยังทำงานกับรถในลานตามเดิม** แต่รถที่กำลังออกจะไม่ถูกหยุดจากการทับซ้อนกับรถบนถนน
- การเคลื่อนที่ช่วงต้นของรถหลังออกสู่ถนนมีข้อยกเว้นชั่วคราวประมาณสองช่วงถนน เพื่อให้รถพ้นประตูทางออก โดยไม่ขโมยช่อง `state.occ` ที่รถบนถนนเดิมครอบครองอยู่ และยังคงการจัดการสัญญาณไฟ/คิวแยกเดิม
- การหลบขวาฉุกเฉินและค้นเส้นทางใหม่จาก v1.5 ยังคงทำงาน และยังแสดงการหลบรถที่กำลังเคลื่อนผ่านจุดรวมเข้า
- การกู้รถหยุดนิ่งเกิน 60 นาทีเกมยังทำงานทุกสถานะ ไม่เปลี่ยนข้อมูลเซฟอาคาร/ระบบเซฟออนไลน์หรือความจุลานจอด
- ปรับ `work/test-parking.cjs`, `work/test-parking-merge.cjs` และ `work/test-parking-emergency.cjs` ให้ตรวจรถออกต่อเนื่อง, ทดสอบรถที่มีการจองช่องถนนเดิมอยู่ และเพิ่มกรณีมีรถจริงจอดขวางอยู่ในเส้นทางรวมเข้าถนน โดยต้องไม่เขียนทับการจองเลนของรถเดิม

## SMGame 2.1.0 — Dynamic Daily Schedule (กิจวัตรประชาชนแบบไดนามิก)

- สำรองโค้ดระบบรถที่ใช้งานได้ไว้แล้วใน `backup-version-2.0-car-bug-fix` โดยไม่เปลี่ยนสาขาแบ็กอัปนี้
- เปลี่ยนวิธีกำหนดเวลาใน `dist/game.js` ให้แต่ละคนมีพฤติกรรมพื้นฐานเฉพาะตัว และวันทำงาน/วันหยุดที่ต่างกัน ไม่ใช้ตารางเวลาเดิมวนซ้ำทุก 100 คนหรือออกเดินทางตรงกันเป็นล็อต
- แต่ละวันมีความคลาดเคลื่อนประมาณ ±20 นาทีจากกิจวัตร พร้อมระยะหน่วงหลังเลิกงาน 3–35 นาที และการตัดสินใจแวะกิจกรรม/กลับบ้านตามบุคลิกและความน่าจะเป็นรายวัน; ช่วงเช้า/เย็นยังมีการเดินทางหนาแน่นตามธรรมชาติ
- เมื่อประชาชนไปทำงานสายจะเพิ่ม `routine.advance` เพื่อออกก่อนในวันถัดไปได้สูงสุด 42 นาที และค่อย ๆ กลับสู่เวลาเดิมเมื่อไปถึงตรงเวลาติดต่อกัน
- ก่อนเลือกกิจกรรมจะตรวจความจุร้าน/ลานจอด และสามารถเปลี่ยนประเภทร้านหรือเลื่อนไปลองใหม่ แทนการวนตัดสินใจทุกเฟรม
- ระบบคิวเหตุการณ์ `state.events` เปลี่ยนเป็น **priority heap** เพื่อเพิ่มและนำเหตุการณ์ออก O(log n) ไม่ต้อง sort ทั้งคิวทุกครั้งที่ประชาชนสร้างตารางใหม่; รองรับการบันทึก โหลด ลบประชาชนและข้ามวัน
- ในหน้าตรวจประชาชนแสดงเวลาของวันนี้จริง พร้อมนาทีที่ออกเร็วขึ้นจากประสบการณ์เดินทาง
- เซฟเดิมที่ใช้ `PARKING_VERSION=5` ยังโหลดได้ โดยคงกิจกรรมที่นัดไว้ของวันปัจจุบัน แล้วใช้ตารางใหม่ในวันต่อไป เซฟออนไลน์และระบบรถ/ลานจอดไม่เปลี่ยน schema
- เพิ่มชุดทดสอบ `work/test-dynamic-citizens.cjs` ครอบคลุมบุคลิก 4 แบบ ความไม่ซ้ำของเวลา ความต่างในแต่ละวัน การปรับเวลาเมื่อมาสาย กิจกรรมหลังเลิกงาน การสืบทอดข้อมูลหลังโหลด และการเรียงเหตุการณ์ของประชาชนจำลอง 5,000 คน

## SMGame 2.2.0 — โหมดประชาชนและแดชบอร์ดข้อมูลจริง
